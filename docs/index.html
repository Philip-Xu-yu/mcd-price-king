价格，怎么算出来

本页展示历史快照；连接 MCP 的完整应用可查询当前门店。
1
取数交给 MCP
完整应用连接个人 Token 后，通过麦当劳 MCP 查询当前门店；本页只展示历史快照。
2
算术交给代码
按已知组成估算拆单差额（单点合计 - 套餐价），并计算营养差异；仅作为快照比较。
3
表达交给人话
结论只有一句："A 更省钱，B 蛋白更多，看你要什么"。省下的钱换算成麦当劳商品。
本页的价格和节省金额基于历史快照与确定性计算，仅用于比较思路；实际售价、库存、券后应付请以当前门店的官方渠道为准。

常见问题

大模型口算价格、折扣、营养并不可靠。本项目金额全部来自确定性计算或 MCP 官方接口，可复现、可核验。
本页试算用内置数据快照，不需要登录。查看自己的券/积分/领券需要自己的 MCP Token（完整应用支持）。
本页不会下单。完整应用有默认关闭的高级下单功能，需选择门店、加载实时菜单并明确确认；订单与支付状态以官方接口为准。
营养来自历史快照中的麦当劳官方营养数据表；套餐营养是已匹配组成项的求和。没有匹配到的数据不会被当作真实营养值，结果仅供快照比较。
